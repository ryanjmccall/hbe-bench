### 🧩 The Physics
We are simulating a Dynamic Hopf Fibration. Every neuron represents a fiber in 4D space. The system must maintain a Linking Number of 1 between all fibers globally. This requires computing the Gauss Linking Integral, which is computationally impossible at scale without analog hardware.
